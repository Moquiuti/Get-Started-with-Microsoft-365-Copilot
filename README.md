# Microsoft 365 Copilot - Estudos e Atividades Práticas

Este repositório reúne minhas anotações, exercícios e atividades práticas realizadas durante os cursos da Microsoft Learn relacionados ao **Microsoft 365 Copilot**.

O objetivo deste material é documentar minha evolução no uso do Copilot aplicado a cenários reais de produtividade, análise de informações, resumo de documentos, organização de reuniões, acompanhamento de e-mails e apoio à tomada de decisão no ambiente corporativo.

## Objetivo do repositório

Centralizar os estudos realizados na trilha de Microsoft 365 Copilot, organizando os conteúdos por curso, módulo e exercício.

Além de registrar os prompts utilizados, este repositório também busca demonstrar como a IA pode ser aplicada de forma prática e responsável em tarefas comuns do dia a dia profissional.

## Conteúdos abordados

Entre os principais temas estudados estão:

* Introdução ao Microsoft 365 Copilot;
* Uso de prompts bem estruturados;
* Resumo de apresentações no PowerPoint;
* Análise de tendências no Excel;
* Identificação de decisões e itens de ação em reuniões do Teams;
* Organização e resumo de e-mails no Outlook;
* Consolidação de informações a partir de múltiplas fontes;
* Uso responsável de IA;
* Boas práticas de privacidade e segurança da informação.

## Organização dos exercícios

Cada exercício possui, sempre que aplicável:

* `README.md` com o objetivo da atividade;
* `prompt-utilizado.md` com o prompt criado para o Copilot;
* `resposta-final.md` com o resultado esperado ou resumo gerado;
* arquivos de apoio anonimizados, quando necessários.

## Cuidados com privacidade

Algumas atividades utilizam cenários baseados em situações profissionais reais. Quando isso acontece, os dados são tratados de forma anonimizada.

Foram removidos ou substituídos:

* nomes de clientes;
* nomes de empresas;
* nomes de pessoas;
* e-mails;
* links internos;
* ambientes reais;
* informações sensíveis;
* dados que possam identificar pessoas, clientes ou projetos reais.

O objetivo é preservar a confidencialidade e seguir boas práticas relacionadas à privacidade e à LGPD.

## Aprendizados principais

Durante os estudos, um dos principais aprendizados foi que o Microsoft 365 Copilot pode gerar muito mais valor quando recebe prompts bem estruturados.

Um bom prompt deve deixar claro:

* o objetivo da tarefa;
* o contexto da solicitação;
* a fonte de informação que deve ser usada;
* o formato esperado da resposta.

Essa abordagem torna as respostas mais úteis, reduz ambiguidades e aproxima o resultado das necessidades reais do usuário.

# Módulo 01 - O que é o Microsoft 365 Copilot?

## Objetivo da unidade

Compreender o que é o Microsoft 365 Copilot, como ele funciona dentro do ecossistema Microsoft 365 e quais são os principais requisitos para sua utilização em ambiente corporativo.

## Resumo

O Microsoft 365 Copilot representa uma nova forma de trabalho, na qual os usuários colaboram com recursos de Inteligência Artificial para aumentar produtividade, criatividade e eficiência nas tarefas diárias.

Ele é integrado aos principais aplicativos do Microsoft 365, como Word, Excel, PowerPoint, Outlook, Teams e outros. Sua proposta é permitir que o usuário utilize linguagem natural para solicitar tarefas, gerar conteúdo, resumir informações, analisar dados, organizar comunicações e apoiar decisões.

O Copilot não deve ser entendido apenas como o ChatGPT incorporado ao Microsoft 365. Ele funciona como um mecanismo de orquestração que combina Grandes Modelos de Linguagem, os aplicativos do Microsoft 365 e os dados corporativos disponíveis ao usuário por meio do Microsoft Graph.

## Exemplos de uso

Alguns exemplos de aplicação do Microsoft 365 Copilot incluem:

* resumir uma longa conversa de e-mails no Outlook;
* criar uma apresentação no PowerPoint com base em um relatório;
* reescrever um parágrafo no Word em outro tom ou estilo;
* resumir reuniões, tópicos de conversa e decisões no Teams.

## Sistema do Microsoft 365 Copilot

O Microsoft 365 Copilot combina três elementos principais:

* Grandes Modelos de Linguagem, também conhecidos como LLMs;
* aplicativos do Microsoft 365;
* dados corporativos acessíveis ao usuário por meio do Microsoft Graph.

Essa combinação permite que o Copilot gere respostas mais contextualizadas, considerando documentos, reuniões, e-mails, chats e demais informações às quais o usuário já possui acesso.

## Segurança, conformidade e privacidade

Um ponto importante da unidade é que o Copilot respeita as políticas de segurança, conformidade e privacidade da organização.

Como ele está integrado ao Microsoft 365, suas respostas são baseadas nos dados que o próprio usuário tem permissão para acessar. Isso significa que o Copilot não deve conceder acesso a informações fora do escopo de permissão do usuário.

## Requisitos principais

Para utilizar o Microsoft 365 Copilot, alguns requisitos podem ser necessários, como:

* conta no Microsoft Entra ID;
* licença adequada do Microsoft 365 Copilot;
* aplicativos Microsoft 365, como Word, Excel, PowerPoint, Outlook e Teams;
* conta OneDrive para determinados recursos;
* configuração adequada do Microsoft Teams;
* habilitação de recursos como transcrição ou gravação para uso do Copilot em reuniões;
* ativação de ferramentas como Loop e Whiteboard, quando aplicável;
* atualização adequada dos aplicativos do Office.

## Aprendizado principal

A principal compreensão desta unidade é que o Microsoft 365 Copilot é uma ferramenta de IA integrada ao ambiente corporativo, capaz de atuar de forma contextualizada com base nos dados e permissões do usuário.

Ele não é apenas um gerador de texto, mas uma camada de inteligência aplicada ao fluxo de trabalho, com potencial para apoiar produtividade, criatividade, colaboração e tomada de decisão.

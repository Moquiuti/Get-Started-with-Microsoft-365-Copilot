# Módulo 02 - Como o Microsoft 365 Copilot funciona?

## Objetivo da unidade

Compreender, em nível conceitual, como o Microsoft 365 Copilot processa uma solicitação do usuário e gera respostas contextualizadas dentro do ambiente Microsoft 365.

## Resumo

O Microsoft 365 Copilot funciona combinando Grandes Modelos de Linguagem, conhecidos como LLMs, com os aplicativos do Microsoft 365 e os dados corporativos disponíveis ao usuário por meio do Microsoft Graph.

Quando o usuário faz uma solicitação em linguagem natural, o Copilot interpreta o pedido, busca o contexto necessário nos dados aos quais o usuário já possui acesso e utiliza esse contexto para gerar uma resposta mais relevante.

Essa integração permite que o Copilot apoie tarefas como resumir documentos, analisar conversas, gerar textos, criar apresentações, organizar informações e auxiliar na tomada de decisão.

## Componentes principais

O funcionamento do Microsoft 365 Copilot envolve três componentes principais:

* **Grandes Modelos de Linguagem:** responsáveis por interpretar, gerar e estruturar linguagem natural.
* **Microsoft Graph:** camada que conecta dados corporativos, como e-mails, arquivos, reuniões, chats e documentos.
* **Aplicativos Microsoft 365:** ferramentas onde o Copilot atua diretamente, como Word, Excel, PowerPoint, Outlook, Teams e outros.

## Fluxo básico de funcionamento

De forma simplificada, o funcionamento pode ser entendido assim:

1. O usuário faz uma solicitação em linguagem natural.
2. O Copilot interpreta o objetivo do pedido.
3. O sistema consulta o contexto disponível no Microsoft Graph, respeitando as permissões do usuário.
4. O modelo de linguagem processa a solicitação com base nesse contexto.
5. O Copilot retorna uma resposta no aplicativo Microsoft 365 utilizado.

## Segurança e permissões

Um ponto importante é que o Copilot respeita as permissões existentes no Microsoft 365. Isso significa que ele não deve apresentar informações que o usuário não teria autorização para acessar diretamente.

O Copilot utiliza o contexto corporativo disponível, mas dentro das regras de segurança, privacidade e conformidade da organização.

## Aprendizado principal

A principal compreensão desta unidade é que o Microsoft 365 Copilot não funciona de forma isolada. Ele depende da integração entre IA generativa, dados corporativos e aplicativos de produtividade.

Seu diferencial está justamente em usar o contexto de trabalho do usuário para gerar respostas mais úteis, específicas e conectadas à rotina profissional.
